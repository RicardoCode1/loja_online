# Loja Virtual

Sistema de loja online desenvolvido durante a UC12 do curso Técnico em Informática.

## Requisitos

- PHP
- Apache
- MySQL ou MariaDB
- Composer
- Git

## Instalação

1. Clone o repositório.
2. Acesse a pasta do projeto.
3. Execute `composer install`.
4. Copie `.env.example` para `.env`.
5. Configure as variáveis do banco.
6. Execute `database/criar_banco.sql`.
7. Inicie Apache e MySQL.
8. Acesse `/loja-virtual/public/`.
